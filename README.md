Coca-Cola Sales Dashboard – Power BI

About the Project
I created this Coca-Cola Sales Dashboard using Power BI to understand sales performance and present important business information in a simple visual format. The dashboard helps explore sales data, track key metrics, and identify sales trends.

Tools Used
- Power BI
- Power Query
- DAX

Key Features
- Sales performance tracking
- KPI cards for important business metrics
- Interactive charts and visualizations
- Date-based analysis
- Data cleaning and transformation using Power Query
- Dashboard filtering for easier data exploration

Project Objective
The main goal of this project is to turn raw Coca-Cola sales data into an interactive dashboard that makes it easier to understand business performance and make data-driven decisions.

What I Learned
- Importing and preparing data in Power BI
- Creating calculated measures using DAX
- Working with date tables
- Designing interactive dashboards
- Presenting business data through charts and KPIs

Conclusion
This project helped me improve my Power BI skills and understand how dashboards can be used to analyze sales data and present useful business insights.
